# UAV Localization Algorithm

Research repository for indoor UAV localization using UWB/INS fusion and
authenticated protection of localization telemetry.

本仓库用于继续开题报告与论文草稿，集中保存算法实现、数据及来源、文献调研、
实验配置与结果。论文以英文为主稿，并维护对应的中文翻译。

## Initialization status

- The research scope comes from the two documents supplied by the author.
- Source documents, implementation, experiments, and manuscripts are being organized.
- No experimental performance or publication-ready conclusion is claimed at initialization.
- Results must be reproducible and distinguish simulation from real flight measurements.

This initial commit verifies the repository's remote write connection.
