**题目：基于UWB/INS融合与加密保护的无人机室内安全定位算法研究**

**摘要**\
针对无人机在室内环境中面临的GNSS信号缺失、遮挡严重、多径干扰和定位数据安全性不足等问题，本文提出一种基于UWB/INS融合的无人机室内安全定位算法。该算法利用超宽带技术在室内定位中的高精度、强穿透性和较好的抗多径能力，实现无人机的基础位置测量；同时引入惯性导航系统，在UWB信号受遮挡或短时失效时提供连续的位置、速度和姿态估计。为提高多源传感器融合精度，本文采用非线性卡尔曼滤波方法对UWB测距信息与INS递推信息进行融合，并通过优化滤波器噪声协方差参数提升算法稳定性和收敛速度。此外，针对UWB与INS数据中可能包含的敏感位置、姿态和飞行状态信息，本文引入对称加密机制，由无人机管理部门与无人机共享密钥，对关键定位数据进行加密保护。研究表明，该方法能够在复杂室内遮挡环境下提高无人机定位的连续性、准确性与安全性，为无人机室内巡检、仓储物流、应急救援等应用提供可靠支撑。

**关键词**\
无人机；室内定位；UWB；INS；非线性卡尔曼滤波；对称加密；安全定位

**1 引言**

随着无人机技术的发展，无人机在室内巡检、仓储管理、工业检测、灾害救援和安防巡逻等领域得到了广泛应用。然而，与室外飞行环境不同，室内环境通常存在墙体、货架、设备、人员等复杂遮挡物，GNSS信号难以稳定接收，甚至完全不可用。同时，室内空间结构复杂，信号反射、绕射和非视距传播现象明显，容易导致定位误差增大。

UWB，即超宽带技术，具有时间分辨率高、测距精度高、抗多径能力强和一定穿透能力等优点，适合用于室内高精度定位。但在动态遮挡环境下，UWB信号仍可能出现短时丢失、测距异常或非视距误差。INS，即惯性导航系统，能够通过加速度计和陀螺仪连续估计无人机运动状态，不依赖外部信号，具有良好的短时自主定位能力。但INS存在误差随时间累积的问题，难以长时间单独使用。

因此，将UWB与INS进行融合，可以充分发挥二者优势：UWB提供绝对位置约束，抑制INS累积误差；INS在UWB受遮挡或失效时提供连续运动估计，提升定位系统的鲁棒性。与此同时，无人机定位数据具有较高敏感性，一旦被非法获取或篡改，可能造成飞行轨迹泄露、控制风险甚至安全事故。因此，有必要在定位算法中引入数据加密机制，提升系统安全性。

本文提出一种基于UWB/INS融合与对称加密保护的无人机室内安全定位算法，通过非线性卡尔曼滤波实现多传感器融合，并结合滤波参数优化提升复杂环境下的定位精度与稳定性。

**2 系统模型**

**2.1 室内无人机定位场景**

设无人机在室内三维空间中飞行，环境中部署若干个位置已知的UWB基站。无人机搭载UWB标签和INS模块，UWB标签与多个基站进行测距，INS模块实时采集加速度和角速度信息。无人机定位系统需要根据传感器数据估计无人机在室内坐标系下的位置、速度和姿态。

无人机状态向量可表示为：

$$X_{k} = \left\lbrack p_{x},p_{y},p_{z},v_{x},v_{y},v_{z},\phi,\theta,\psi \right\rbrack^{T}$$

其中，$p_{x},p_{y},p_{z}$表示无人机位置，$v_{x},v_{y},v_{z}$表示速度，$\phi,\theta,\psi$
分别表示横滚角、俯仰角和偏航角。

**2.2 UWB测距模型**

假设第i个UWB基站坐标为：

$$A_{i} = \left( x_{i},y_{i},z_{i} \right)$$

无人机位置为：

$$P = (x,y,z)$$

则无人机与第 i 个基站之间的理想距离为：

$$d_{i} = \sqrt{\left( x - x_{i} \right)^{2} + \left( y - y_{i} \right)^{2} + \left( z - z_{i} \right)^{2}}$$

实际测距值可表示为：

$${\widehat{d}}_{i} = d_{i} + n_{i} + b_{i}$$

其中，$n_{i}$为测量噪声，$b_{i}$
为非视距或遮挡引起的偏差。当环境遮挡较弱时，$b_{i}$
较小；当动态遮挡严重时，$b_{i}$ 可能明显增大。

**2.3 INS递推模型**

INS通过加速度计和陀螺仪获得无人机的运动信息。其基本递推过程为：

$$v_{k} = v_{k - 1} + a_{k}\Delta t$$

$$p_{k} = p_{k - 1} + v_{k - 1}\Delta t + \frac{1}{2}a_{k}\Delta t^{2}$$

其中，$a_{k}$
为经过姿态转换后的加速度，$\Delta t$为采样周期。由于传感器零偏、噪声和积分误差的存在，INS误差会随时间逐渐累积，因此需要UWB测量信息进行周期性校正。

**3 基于UWB/INS的融合定位算法**

**3.1 算法总体思想**

本文算法主要包括四个部分：

1.  UWB测距数据采集与异常检测；

2.  INS运动状态递推；

3.  基于非线性卡尔曼滤波的UWB/INS数据融合；

4.  定位数据加密与安全传输。

在UWB信号正常时，系统利用UWB测距结果修正INS估计误差；当UWB信号受遮挡或出现异常时，系统降低异常测量权重，主要依赖INS进行短时预测；当UWB信号恢复后，再通过滤波更新修正累积误差。

**3.2 非线性卡尔曼滤波融合**

由于UWB测距方程是非线性的，本文采用扩展卡尔曼滤波或无迹卡尔曼滤波进行融合。以扩展卡尔曼滤波为例，其过程包括预测和更新两个阶段。

预测阶段：

$${\widehat{X}}_{k|k - 1} = f\left( {\widehat{X}}_{k - 1|k - 1},u_{k} \right)$$

$$P_{k|k - 1} = F_{k}P_{k - 1|k - 1}F_{k}^{T} + Q_{k}$$

其中，$f( \cdot )$ 为INS状态递推函数，$u_{k}$ 为惯性测量输入，$F_{k}$
为状态转移雅可比矩阵，$Q_{k}$为过程噪声协方差矩阵。

更新阶段：

$$K_{k} = P_{k|k - 1}H_{k}^{T}\left( H_{k}P_{k|k - 1}H_{k}^{T} + R_{k} \right)^{- 1}$$

$${\widehat{X}}_{k|k} = {\widehat{X}}_{k|k - 1} + K_{k}\left( Z_{k} - h\left( {\widehat{X}}_{k|k - 1} \right) \right)$$

$$P_{k|k} = \left( I - K_{k}H_{k} \right)P_{k|k - 1}$$

其中，$Z_{k}$ 为UWB测距观测值，$h( \cdot )$
为UWB非线性观测函数，$H_{k}$为观测函数雅可比矩阵，$R_{k}$为测量噪声协方差矩阵。

**3.3 动态遮挡下的鲁棒处理**

在动态遮挡环境下，UWB测距可能出现异常跳变。为提高系统可靠性，本文引入残差检测机制：

$$r_{k} = Z_{k} - h\left( {\widehat{X}}_{k|k - 1} \right)$$

当残差超过设定阈值时，认为该测距值可能受到遮挡或非视距传播影响。此时可采用以下策略：

1.  增大对应测量噪声协方差 $R_{k}$，降低异常UWB数据权重；

2.  剔除明显异常的测距数据；

3.  在短时UWB失效期间依靠INS递推维持定位连续性；

4.  当UWB信号恢复后重新进行滤波校正。

该机制能够避免异常UWB测距对融合结果造成过大影响，提高无人机在复杂室内环境下的定位稳定性。

**4 定位数据安全保护机制**

无人机定位过程中产生的位置、速度、姿态、UWB测距和INS原始数据均可能涉及敏感信息。若这些数据在传输或存储过程中被窃取，可能导致无人机飞行轨迹泄露；若被篡改，则可能影响定位结果，进而威胁飞行安全。

为此，本文采用对称加密体制对敏感信息进行保护。无人机管理部门与无人机预先共享密钥
K，无人机在上传或交换定位数据前，使用该密钥对数据进行加密：

$$C = E_{K}(M)$$

其中，M 为明文定位数据，C 为密文数据，$E_{K}( \cdot )$
为对称加密函数。管理部门接收后使用同一密钥进行解密：

$$M = D_{K}(C)$$

对称加密具有计算速度快、资源开销低的优点，适合无人机这类计算和功耗受限的平台。实际系统中可采用AES等成熟加密算法，并结合消息认证码防止数据被篡改。

**5 滤波器参数优化**

非线性卡尔曼滤波的性能高度依赖过程噪声协方差Q 和测量噪声协方差 R
的设置。若 Q设置过小，系统会过度信任INS模型，导致对机动变化响应迟缓；若
Q 设置过大，则预测结果波动明显。若
R设置过小，系统会过度信任UWB测量，容易受遮挡异常影响；若
R设置过大，则UWB修正作用不足，INS误差难以及时抑制。

本文采用基于残差自适应调整的参数优化方法。当UWB残差较小时，说明测量可信度较高，可适当减小
R，增强UWB校正作用；当残差较大时，说明测量可能受遮挡影响，应增大
R，降低异常测量权重。其调整形式可表示为：

$$R_{k} = \alpha R_{k - 1} + (1 - \alpha)r_{k}r_{k}^{T}$$

其中，$\alpha$为平滑因子。通过动态调整滤波参数，系统能够根据环境变化自适应平衡UWB与INS数据权重，从而提升融合效率与定位精度。

**6 算法流程**

本文提出的UWB/INS安全定位算法流程如下：

1.  初始化无人机状态、UWB基站坐标、滤波协方差矩阵和共享加密密钥；

2.  INS模块实时采集加速度和角速度数据，进行状态预测；

3.  UWB模块获取与多个基站之间的测距信息；

4.  对UWB测距数据进行残差检测和异常判断；

5.  根据遮挡情况自适应调整测量噪声协方差；

6.  利用非线性卡尔曼滤波完成UWB/INS融合更新；

7.  输出无人机位置、速度和姿态估计结果；

8.  对敏感定位数据进行对称加密后传输或存储；

9.  循环执行，直至任务结束。

**7 实验分析**

为验证本文算法的有效性，可构建室内无人机飞行实验环境，在房间、仓库或厂房中部署多个UWB基站，并设置动态遮挡物模拟人员移动、货架遮挡和复杂墙体反射等情况。实验可比较以下几种方法：

1.  单独UWB定位方法；

2.  单独INS递推方法；

3.  普通UWB/INS融合方法；

4.  本文提出的自适应UWB/INS安全定位方法。

评价指标包括平均定位误差、最大定位误差、轨迹连续性、遮挡恢复时间和数据安全性。

预期结果表明，单独UWB方法在视距条件下具有较高精度，但在遮挡情况下误差波动较大；单独INS方法短时稳定，但误差随时间累积明显；普通融合方法能够改善定位精度，但对异常UWB数据较敏感；本文方法通过残差检测和滤波参数优化，能够在动态遮挡条件下保持较好的定位连续性和稳定性，同时通过加密机制提升定位数据传输安全性。

**8 结论**

本文针对室内无人机定位中GNSS不可用、环境遮挡严重、UWB测距异常和定位数据安全性不足等问题，提出了一种基于UWB/INS融合与对称加密保护的室内安全定位算法。该算法利用UWB提供高精度绝对测距信息，利用INS提供连续运动预测，并通过非线性卡尔曼滤波实现二者融合。在动态遮挡情况下，算法根据残差变化自适应调整滤波参数，降低异常UWB测距对定位结果的影响。同时，本文引入对称加密机制，对UWB和INS敏感数据进行加密保护，提高了定位系统的安全性。

总体来看，该方法能够有效提升无人机在复杂室内环境下的定位精度、连续性、鲁棒性和数据安全性。未来研究可进一步结合视觉传感器、激光雷达或地图约束信息，构建更加完善的多源融合定位系统，并在真实无人机平台上开展大规模实验验证。
